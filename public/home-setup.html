Local vault · no cloud reclaim

Home box + Cloudflare Tunnel

Run Embified on a mini PC, NUC, Pi, or always-on laptop at home. Cloudflare Tunnel gives you a public HTTPS URL without opening ports on your router — required for Meta Cloud API webhooks, optional for Baileys-only.

The machine must never sleep. Disable suspend/hibernate, keep it plugged in, and prefer an SSD for Baileys session + media. This path avoids Oracle idle reclaim, but you own power, disk, and backups.

1 · Hardware

  • Any always-on Linux box (Ubuntu 22.04+ recommended). Raspberry Pi 4/5 with 4–8 GB + USB SSD works.
  • Skip flaky SD cards as the only store — put DATA_DIR / AUTH_DIR on SSD.
  • Optional: Tailscale for private admin SSH; Tunnel still handles public HTTPS.

2 · Install Embified

curl -fsSL https://raw.githubusercontent.com/koyguy/embified/main/scripts/home-box/install-embified.sh | bash
# or, from a clone:
sudo bash scripts/home-box/install-embified.sh

Installs Node 22, clones to /opt/embified, creates systemd embified.service, sets a vault password prompt, binds to localhost:80 by default (Tunnel terminates HTTPS).

3 · Cloudflare Tunnel

Named tunnel (stable hostname — preferred)

sudo bash scripts/home-box/install-cloudflared.sh
sudo bash scripts/home-box/setup-named-tunnel.sh your-subdomain.example.com

Needs a free Cloudflare account + a domain on Cloudflare DNS. Points the hostname at http://127.0.0.1:80.

Quick tunnel (testing only — URL changes on restart)

sudo bash scripts/home-box/start-quick-tunnel.sh

4 · Connect WhatsApp

  1. Open https://<your-tunnel-host>/login with the vault password.
  2. Baileys: choose Linked device and scan QR (no public webhook required).
  3. Cloud API: follow /cloud-setup; paste the tunnel origin as the public HTTPS origin.
