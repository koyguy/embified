Open an Oracle Always Free tenancy

Always Free still needs a card in most regions; you are not charged if you stay within free limits. Pick your home region carefully — Always Free compute is home-region only.

  1. Create an account at Oracle Cloud Free Tier.
  2. Finish email + payment verification until the tenancy is active (not stuck in “verifying”).
  3. In the console, copy your compartment OCID (root compartment is fine for a personal vault).
  4. Generate an SSH keypair if you do not have one (ssh-keygen -t ed25519).

Provision with Resource Manager

  1. Download terraform.tfvars (button below).
  2. On GitHub, grab infra/oci-resource-manager/ from koyguy/embified — zip that folder (tfvars at the zip root next to the .tf files).
  3. OCI Console → Developer Services → Resource Manager → Stacks → Create stack → upload zip → Apply.
  4. When Apply finishes, copy public_ip. Wait 5–10 minutes for cloud-init.
  5. Before sharing the IP, SSH in and set the inbox password:
ssh -i <private-key> ubuntu@<public_ip>
sudo install -d -m 700 /etc/embified
echo 'EMBIFIED_AUTH_PASSWORD=your-strong-password' | sudo tee /etc/embified/auth.env
sudo chmod 600 /etc/embified/auth.env
sudo systemctl restart embified

Then open http://<public_ip>/vault and http://<public_ip>/login. Link WhatsApp from the inbox. Prefer a home box? /home-setup. Prefer official Cloud API (no Baileys)? See /cloud-setup after the VM is up.
